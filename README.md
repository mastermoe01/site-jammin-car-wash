# site-jammin-car-wash

Demo website for Jammin Car Wash (Lutz & Wesley Chapel, FL), built by Raqm AI & Automation.
Next.js App Router, React Three Fiber, Motion, Tailwind 4. Content traces to the studio client folder `clients/jammin-car-wash/`.

Videos: drop `walkthrough.mp4` / `flyover.mp4` (+ `poster-*.jpg`) into `public/videos/<subject-slug>/` (`21356-walmart-way`, `3706-windcrest-dr`) and push.
